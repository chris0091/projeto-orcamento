# Projeto de Orçamento

Este projeto foi desenvolvido durante meus estudos de desenvolvimento web.

## Sobre o projeto

Uma página com formulário para solciitação de orçamemento, utilizando HTML, CSS e JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Formulário para solicitação de orçamento.
- Campos para nome, e-mail e mensagem.
- Validação de campos obrigatórios.
- Botão para limpar o formulário.
- Mensagem de confirmação após o envio.

## Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador.

O projeto utiliza HTML, CSS e JavaScript,
portanto não precisa de instalação de dependências.
